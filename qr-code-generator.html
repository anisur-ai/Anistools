How to make a QR code

QR কোড বানানোর নিয়ম

  1. Type or paste your link, text, email address (mailto:…) or phone number (tel:…) into the box.
  2. Choose the QR color and background. Dark code on a light background scans best.
  3. The QR code updates as you type. You can also press "Generate QR code".
  4. Press "Download PNG". The image is a 512 × 512 pixel PNG.
  1. আপনার লিংক, লেখা, ইমেইল (mailto:…) বা ফোন নম্বর (tel:…) ঘরে লিখুন বা পেস্ট করুন।
  2. QR-এর রং আর ব্যাকগ্রাউন্ডের রং বেছে নিন। হালকা ব্যাকগ্রাউন্ডে গাঢ় রংের কোড সবচেয়ে ভালো স্ক্যান হয়।
  3. টাইপ করার সাথে সাথেই QR কোড আপডেট হয়। চাইলে "QR কোড তৈরি করুন" বাটনও চাপতে পারেন।

Tips for a QR code that scans reliably

যেভাবে QR কোড সহজে স্ক্যান হবে

  • Keep strong contrast between the code and the background. Don't invert the colors (light code on a dark background), because many scanners can't read it.
  • Shorter text makes a simpler code that is easier to scan. For websites, use a short full address starting with https://.
  • Test the code with your phone before printing or sharing it.
  • Leave a blank margin around the code and don't print it too small.
  • This tool makes static QR codes: the data is stored in the image itself, so the code never expires and doesn't track scans.
  • কোড আর ব্যাকগ্রাউন্ডের মধ্যে রঙের পার্থক্য স্পষ্ট রাখুন। রং উল্টে দেবেন না (গাঢ় ব্যাকগ্রাউন্ডে হালকা কোড), কারণ অনেক স্ক্যানার সেটা পড়তে পারে না।
  • লেখা যত ছোট, কোড তত সহজ আর স্ক্যান করা তত সুবিধাজনক। ওয়েবসাইটের জন্য https:// দিয়ে শুরু করা ছোট পূর্ণ ঠিকানা দিন।
  • ছাপানো বা শেয়ার করার আগে নিজের ফোনে স্ক্যান করে দেখুন।
  • কোডের চারপাশে ফাঁকা জায়গা রাখুন, আর খুব ছোট করে ছাপবেন না।
  • এই টুল স্ট্যাটিক QR কোড বানায়: তথ্য ছবির ভেতরেই থাকে, তাই কোডের মেয়াদ শেষ হয় না আর কে স্ক্যান করল তা ট্র্যাক হয় না।

Frequently asked questions

সচরাচর জিজ্ঞাসা

Is this QR code generator really free?

Yes. There is no sign-up, no watermark and no limit on how many codes you create.

Do the QR codes expire?

No. The link or text is encoded directly in the image, so the code keeps working as long as the destination itself (such as your website) is online.

Is my link or text uploaded anywhere?

No. The code is generated in your browser, and what you type is not sent anywhere.

Why won't my QR code scan?

The usual reasons are low contrast between the code and the background, inverted colors, very long text, or printing it too small. Use a dark code on a light background and test it with your phone.

What image size do I get?

A 512 × 512 pixel PNG, which is sharp enough for websites, documents and small prints.
