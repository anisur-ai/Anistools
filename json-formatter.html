How to use the JSON formatter

        
JSON ফরম্যাটার ব্যবহারের নিয়ম

    2. 
          
  2. Choose the indent (2 spaces, 4 spaces or Tab). Tick "Sort keys A–Z" if you want the keys of every object in alphabetical order.
    3. 
          
  3. Press "Format" to make it easy to read, "Minify" to squeeze it onto one line, or "Validate" to only check it. Ctrl + Enter (⌘ + Enter on a Mac) also formats.
    4. 
          
  4. The status bar checks your JSON a moment after you stop typing. If there is a mistake, it tells you what is wrong, gives the line and column, and highlights the line. Press "Go to error" to jump there.

What "Fix errors" can and cannot repair

        
"ভুল ঠিক করুন" বাটন যা পারে আর যা পারে না

        
    
          
  • It removes comments (// note and /* note */).
    • 
          
  • It removes a trailing comma before a closing } or ].
    • 
          
  • It changes 'single quotes' around text and keys into "double quotes".
    • 
          
  • It puts double quotes around keys that have none, such as {name: "Anis"}.
    • 
          
  • It changes True, False and None into true, false and null.
    • 
          
  • It cannot guess missing commas, brackets, braces or values. If something is still wrong after the repairs, the output box shows the partly repaired text, and the status bar gives the line and column of the remaining problem in that text.
    • 
          
  • It repairs the syntax only and cannot know what you meant, so check the result before you use it. Your input stays as it is until you press "Use as input".
    • 
        

        
    
          
  • কমেন্ট মুছে দেয় (// note আর /* note */)।
    • 
          
  • শেষ } বা ]-এর আগের বাড়তি কমা সরিয়ে দেয়।
    • 
          
  • লেখা ও কী-এর চারপাশের 'সিঙ্গেল কোটেশন'-কে "ডাবল কোটেশন"-এ বদলায়।
    • 
          
  • কোটেশন ছাড়া কী-তে ডাবল কোটেশন বসায়, যেমন {name: "Anis"}।
    • 
          
  • True, False আর None-কে true, false আর null করে।
    • 
          
  • কমা, বন্ধনী বা মান বাদ পড়লে সেটা আন্দাজ করতে পারে না। মেরামতের পরেও কিছু ভুল থাকলে আউটপুট ঘরে আংশিক মেরামত করা লেখা দেখায়, আর স্ট্যাটাস বার ওই লেখার কোন লাইন ও কলামে বাকি ভুলটা আছে তা জানায়।
    • 
          
  • এটা শুধু গঠন ঠিক করে, আপনি কী বোঝাতে চেয়েছেন তা জানতে পারে না, তাই ফল ব্যবহারের আগে দেখে নিন। "ইনপুট বানান" না চাপা পর্যন্ত আপনার ইনপুট যেমন ছিল তেমনই থাকে।

Reading the numbers below the tool

        
টুলের নিচের সংখ্যাগুলো কীভাবে পড়বেন

        
    
          
  • Size: the size of your input in bytes, KB or MB. It is counted in UTF-8, so one Bengali letter takes 3 bytes.
    • 
          
  • Lines: the number of lines in your input.
    • 
          
  • Keys: the total number of keys in all objects, including nested ones.
    • 
          
  • Depth: how many levels of objects and arrays sit inside each other. {} has a depth of 1, and {"a": {}} has a depth of 2.
    • 
          
  • Type: whether the JSON is an Object, Array, String, Number, Boolean or Null.
    • 
          
  • Keys, Depth and Type appear only when the JSON is valid.
    • 
        

        
    
          
  • সাইজ: আপনার ইনপুটের আকার, বাইট, কেবি বা এমবিতে। গণনা UTF-8-এ হয়, তাই একটি বাংলা অক্ষর ৩ বাইট নেয়।
    • 
          
  • লাইন: আপনার ইনপুটে মোট কতগুলো লাইন আছে।
    • 
          
  • কী: ভেতরের অবজেক্টসহ সব অবজেক্টের মোট কী সংখ্যা।
    • 
          
  • গভীরতা: অবজেক্ট আর অ্যারে কত স্তর একটার ভেতরে আরেকটা আছে। {}-এর গভীরতা ১, আর {"a": {}}-এর গভীরতা ২।
    • 
          
  • ধরন: JSON-টি অবজেক্ট, অ্যারে, স্ট্রিং, সংখ্যা, বুলিয়ান নাকি নাল।
    • 
          
  • কী, গভীরতা আর ধরন শুধু তখনই দেখায় যখন JSON সঠিক।

Frequently asked questions

        
সচরাচর জিজ্ঞাসা

        

          
Is this JSON formatter free?
            
Yes. It is free, needs no sign-up and adds no watermark.

          
Is my JSON uploaded or saved?
            
No. Your JSON is processed in your browser and is not sent to our servers or saved. We use Google Analytics to count visits, but the JSON you enter is not part of that. Because nothing is saved, your input disappears when you close or reload the page, so copy or download it first. As with any online tool, avoid pasting real passwords or secret keys.

          
What is JSON?
            
JSON (JavaScript Object Notation) is a simple text format for storing and exchanging data. Websites, apps and APIs use it a lot, and so do many settings files. It is built from objects like {"key": value}, arrays like [1, 2, 3], text in double quotes, numbers, true, false and null.

          
What is the difference between Format and Minify?
            
Format adds line breaks and indentation so the JSON is easy to read. Minify removes every space and line break that is not inside text, which makes the data smaller and is handy when you send JSON over a network.

          
Why does it say my JSON is invalid?
            
Usually because of a mistake from the table above, such as a trailing comma, single quotes or a missing comma. The line and column show where the tool noticed the problem. Sometimes the real mistake is just before that spot. For example, a missing comma between two items is noticed at the start of the second item.

          
Is there a size limit?
            
There is no fixed limit. Files of several megabytes may take a moment on an older phone. Above about 5 MB, checking as you type is switched off, and the JSON is checked only when you press a button.

          
Does it change my numbers or text?
            
No. Formatting only changes spaces and line breaks, and the order of keys if you tick "Sort keys A–Z". Numbers, including very long ones such as 12345678901234567890, and the text inside strings are kept exactly as written. Tools that first turn JSON into JavaScript numbers can round long numbers, but this tool keeps the digits as they are.

          
Can I use a JSON file from my device?
            
Yes. Press "Upload", or drag a .json or .txt file onto the input box. The file is read in your browser and is not uploaded. Press "Download" to save the result as a .json file.

        

        

          
এই JSON ফরম্যাটার কি ফ্রি?
            
হ্যাঁ। এটা ফ্রি, সাইনআপ লাগে না, আর ওয়াটারমার্কও নেই।

          
আমার JSON কি আপলোড বা সংরক্ষণ হয়?
            
না। আপনার JSON ব্রাউজারেই প্রসেস হয়, আমাদের সার্ভারে পাঠানো বা সংরক্ষণ করা হয় না। কতজন সাইটে আসছেন তা গুনতে আমরা Google Analytics ব্যবহার করি, কিন্তু আপনার দেওয়া JSON তার অংশ নয়। কিছুই সংরক্ষণ হয় না বলে পেজ বন্ধ করলে বা রিলোড দিলে ইনপুট মুছে যায়, তাই আগে কপি বা ডাউনলোড করে নিন। যেকোনো অনলাইন টুলের মতোই আসল পাসওয়ার্ড বা সিক্রেট কী পেস্ট করবেন না।

          
JSON কী?
            
JSON (JavaScript Object Notation) হলো তথ্য জমা রাখা ও আদান-প্রদানের একটি সহজ টেক্সট ফরম্যাট। ওয়েবসাইট, অ্যাপ আর API এটা খুব ব্যবহার করে, অনেক সেটিংস ফাইলেও এটা থাকে। এটা তৈরি হয় {"key": value}-এর মতো অবজেক্ট, [1, 2, 3]-এর মতো অ্যারে, ডাবল কোটেশনে লেখা টেক্সট, সংখ্যা, true, false আর null দিয়ে।

          
ফরম্যাট আর মিনিফাইয়ের পার্থক্য কী?
            
ফরম্যাট লাইন-ব্রেক আর ইনডেন্ট যোগ করে, যাতে JSON পড়া সহজ হয়। মিনিফাই লেখার বাইরের সব স্পেস ও লাইন-ব্রেক সরিয়ে দেয়, ফলে ডেটা ছোট হয়, নেটওয়ার্কে JSON পাঠানোর সময় এটা কাজে লাগে।

          
"JSON ভুল" দেখাচ্ছে কেন?
            
সাধারণত ওপরের টেবিলের কোনো ভুলের কারণে, যেমন শেষে বাড়তি কমা, সিঙ্গেল কোটেশন বা কমা বাদ পড়া। লাইন ও কলাম দেখায় টুল কোথায় সমস্যাটা টের পেয়েছে। মাঝে মাঝে আসল ভুলটা ওই জায়গার ঠিক আগেই থাকে। যেমন, দুই আইটেমের মাঝে কমা বাদ পড়লে সেটা দ্বিতীয় আইটেমের শুরুতে ধরা পড়ে।

          
সাইজের কি কোনো সীমা আছে?
            
নির্দিষ্ট কোনো সীমা নেই। কয়েক মেগাবাইটের ফাইল পুরনো ফোনে একটু সময় নিতে পারে। প্রায় ৫ এমবির বেশি হলে টাইপ করার সময় নিজে থেকে যাচাই বন্ধ থাকে, আর বাটন চাপলে তবেই JSON যাচাই হয়।

          
আমার সংখ্যা বা লেখা কি বদলে যায়?
            
না। ফরম্যাটে শুধু স্পেস আর লাইন-ব্রেক বদলায়, আর "কী A–Z সাজান" টিক দিলে কী-এর ক্রম। সংখ্যা, এমনকি 12345678901234567890-এর মতো খুব বড় সংখ্যাও, আর স্ট্রিংয়ের ভেতরের লেখা যেমন ছিল ঠিক তেমনই থাকে। যেসব টুল আগে JSON-কে JavaScript-এর সংখ্যায় বদলে নেয়, তারা বড় সংখ্যা গোল করে ফেলতে পারে; এই টুল অঙ্কগুলো যেমন লেখা তেমনই রাখে।

          
আমার ডিভাইস থেকে JSON ফাইল খুলতে পারি?
            
হ্যাঁ। "ফাইল" বাটন চাপুন বা একটি .json অথবা .txt ফাইল ইনপুট ঘরের ওপর টেনে এনে ছাড়ুন। ফাইলটি আপনার ব্রাউজারেই পড়া হয়, আপলোড হয় না। ফলাফল .json ফাইল হিসেবে সংরক্ষণ করতে "ডাউনলোড" চাপুন।
