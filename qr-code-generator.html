How to make a QR code

QR কোড বানানোর নিয়ম

  1. Choose what the QR code should hold: a link or text, Wi-Fi details, an email or a phone number.
  2. Fill in the details. The QR code updates as you type.
  3. If you like, change the colors, size, margin and error correction under "Style options".
  4. Press "Download PNG" for everyday use, or "Download SVG" for print and design work where you need sharp edges at any size. Scan the code with your phone to test it.
  1. QR কোডে কী থাকবে বেছে নিন: লিংক বা লেখা, Wi-Fi-এর তথ্য, ইমেইল বা ফোন নম্বর।
  2. তথ্য লিখুন। টাইপ করার সাথে সাথেই QR কোড আপডেট হয়।
  3. চাইলে "স্টাইল অপশন" থেকে রং, সাইজ, মার্জিন আর ত্রুটি সংশোধন বদলাতে পারেন।
  4. সাধারণ কাজের জন্য "PNG ডাউনলোড" চাপুন। প্রিন্ট বা ডিজাইনের কাজে যেখানে যেকোনো সাইজে ধার পরিষ্কার থাকা দরকার, সেখানে "SVG ডাউনলোড" নিন। ফোনে স্ক্যান করে পরীক্ষা করে নিন।

What you can put in a QR code

QR কোডে কী কী রাখা যায়

  • Link or text: opens a website or shows your text when scanned. For websites, start the address with https://.
  • Wi-Fi: lets guests join your network without typing the password. The name and password are stored inside the code, so share it only with people you trust.
  • Email: opens a new email with the address, subject and message already filled in.
  • Phone: opens the dialer with the number ready to call.
  • লিংক বা লেখা: স্ক্যান করলে ওয়েবসাইট খোলে বা লেখা দেখায়। ওয়েবসাইটের ঠিকানা https:// দিয়ে শুরু করুন।
  • Wi-Fi: অতিথিরা পাসওয়ার্ড না লিখেই আপনার নেটওয়ার্কে যুক্ত হতে পারে। নাম আর পাসওয়ার্ড কোডের ভেতরেই থাকে, তাই শুধু বিশ্বস্ত মানুষের সঙ্গে শেয়ার করুন।
  • ইমেইল: ঠিকানা, বিষয় আর বার্তা আগে থেকে ভরা একটি নতুন ইমেইল খোলে।
  • ফোন: নম্বরসহ ডায়ালার খোলে, শুধু কল করলেই হয়।

Tips for a QR code that scans reliably

যেভাবে QR কোড সহজে স্ক্যান হবে

  • Keep strong contrast between the code and the background. A dark code on a light background works best.
  • Don't invert the colors (a light code on a dark background). Some scanner apps can't read it.
  • Shorter content makes a simpler code that is easier to scan. Higher error correction makes the code denser.
  • Keep the margin on "Standard" and don't print the code smaller than about 2 cm (0.8 in).
  • Always test the code with your phone before printing or sharing it.
  • This tool makes static QR codes: the data is stored in the image itself, so the code never expires and doesn't track scans.
  • কোড আর ব্যাকগ্রাউন্ডের মধ্যে রঙের পার্থক্য স্পষ্ট রাখুন। হালকা ব্যাকগ্রাউন্ডে গাঢ় কোড সবচেয়ে ভালো কাজ করে।
  • রং উল্টাবেন না (গাঢ় ব্যাকগ্রাউন্ডে হালকা কোড)। কিছু স্ক্যানার অ্যাপ সেটা পড়তে পারে না।
  • লেখা যত ছোট, কোড তত সহজ আর স্ক্যান করা তত সুবিধাজনক। ত্রুটি সংশোধনের স্তর বাড়ালে কোড ঘন হয়।
  • মার্জিন "সাধারণ" রাখুন, আর কোড প্রায় ২ সেমি-র চেয়ে ছোট ছাপবেন না।
  • ছাপানো বা শেয়ার করার আগে নিজের ফোনে স্ক্যান করে দেখুন।
  • এই টুল স্ট্যাটিক QR কোড বানায়: তথ্য ছবির ভেতরেই থাকে, তাই কোডের মেয়াদ শেষ হয় না আর কে স্ক্যান করল তা ট্র্যাক হয় না।

Frequently asked questions

সচরাচর জিজ্ঞাসা

Is this QR code generator really free?

Yes. There is no sign-up, no watermark and no limit on how many codes you create.

Do the QR codes expire?

No. The data is encoded directly in the image, so the code keeps working for as long as the destination itself, such as your website, is online.

Is my link, text or Wi-Fi password uploaded anywhere?

No. The code is created in your browser and what you type is not sent to our servers.

Should I download PNG or SVG?

PNG is an ordinary image, good for websites, documents and chats. SVG is a vector file that stays sharp at any size, which makes it the better choice for posters, stickers and professional printing.

What is error correction?

It adds extra data so the code can still be read if part of it is dirty or damaged. Higher levels survive more damage but make the code denser. "Medium" is a good choice for most uses.

Why won't my QR code scan?

The usual reasons are low contrast between the code and the background, inverted colors, very long content, no margin around the code, or printing it too small. Use a dark code on a light background and test it with your phone.

এই QR কোড জেনারেটর কি সত্যিই ফ্রি?

হ্যাঁ। সাইনআপ লাগে না, ছবিতে ওয়াটারমার্ক নেই, আর যত খুশি কোড বানাতে পারবেন।

QR কোডের কি মেয়াদ শেষ হয়?

না। তথ্য সরাসরি ছবির ভেতরেই থাকে, তাই গন্তব্য (যেমন আপনার ওয়েবসাইট) চালু থাকলে কোডও কাজ করবে।

আমার লিংক, লেখা বা Wi-Fi পাসওয়ার্ড কি কোথাও আপলোড হয়?

না। কোডটি আপনার ব্রাউজারেই তৈরি হয়, আপনি যা লেখেন তা আমাদের সার্ভারে পাঠানো হয় না।

PNG নেব নাকি SVG?

PNG সাধারণ ছবি, ওয়েবসাইট, ডকুমেন্ট আর চ্যাটের জন্য ভালো। SVG হলো ভেক্টর ফাইল, যেকোনো সাইজে ধারালো থাকে, তাই পোস্টার, স্টিকার আর পেশাদার প্রিন্টের জন্য এটাই ভালো।

ত্রুটি সংশোধন (error correction) কী?

এটা বাড়তি তথ্য যোগ করে, যাতে কোডের কিছু অংশ নোংরা বা নষ্ট হলেও পড়া যায়। উঁচু স্তরে বেশি নষ্ট হলেও পড়া যায়, তবে কোড ঘন হয়। বেশিরভাগ কাজের জন্য "মাঝারি" ঠিক আছে।

আমার QR কোড স্ক্যান হচ্ছে না কেন?

সাধারণ কারণ হলো কোড আর ব্যাকগ্রাউন্ডের রঙের পার্থক্য কম, রং উল্টানো, লেখা অনেক বড়, কোডের চারপাশে মার্জিন না থাকা, বা খুব ছোট করে ছাপা। হালকা ব্যাকগ্রাউন্ডে গাঢ় কোড ব্যবহার করুন আর ফোনে স্ক্যান করে দেখুন।
